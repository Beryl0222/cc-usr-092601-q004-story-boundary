# 文化短视频事实边界台

管理文化短视频事实主张、素材许可、翻译和渠道发布之间的引用事件，回答一句解说究竟来自传承人口述、公开资料、作者体验还是解释性类比，并在来源撤回与结论更正时做范围化处置。

## 目录

- `contracts/domain.schema.json`：对象、事件、载荷字段与枚举约定。
- `data/sample.json`：可直接校验的单事件联调样例。
- `data/sample.stream.json`：覆盖完整叙事的事件流（授权 → 主张 → 争议 → 翻译双签 → 冻结 → 多渠道发布 → 归档 → 更正传播）。
- `src/contracts.js`：信封、时间、版本与载荷基础校验（不改写输入）。
- `src/service.js`：事件溯源领域服务，承载全部业务不变量与查询投影。
- `src/cli.js`：契约校验命令行入口（接受单事件或事件数组）。
- `tests/`：契约与领域服务测试。
- `docs/domain.md`：领域对象、事件语义与不变量清单。

## 领域规则速览

- 撰稿人可以提出解释，但推测/口述/体验/类比不能登记为已确认事实。
- 传承人确认自身经历不等于批准历史结论；历史结论由事实编辑签署。
- 翻译候选必须由事实编辑与跨语种审校分别签署（两人）。
- 发布前冻结片段实际引用的主张、必带限定、翻译选择与签署指纹。
- 平台回执重放不增加发布；同编号但片段/字幕指纹不同则隔离，不覆盖在线版本。
- 来源撤回或结论更正：未发布稿暂停，在线版本范围化传播更正，归档版本保留当时上下文。
- 接口按渠道和语言返回措辞、必带限定与许可状态；公开查询隐藏私人联系方式。
- 后台传播任务失败记检查点，故障恢复后重放事件继续传播。
- 从任一句字幕指纹可追到证据、翻译选择、审核责任和未决争议。

## 编译检查

```bash
npm run build
```

## 样例校验

```bash
npm run check:sample
```

样例有效时输出 `valid`；发现问题时逐行给出序号、事件标识、字段、代码和中文说明，并返回非零状态。
